## Descripción del Proyecto
Aplicación gráfica desarrollada en PyQt5 e integrada con Pandas y Matplotlib para el análisis visual del inventario comercial en cinco sucursales de El Salvador (San Salvador, Santa Ana, San Miguel, La Libertad y Sonsonate).

## Estructura del Repositorio
- `codigo_fuente.py`: Script principal con la interfaz PyQt5 y visualizaciones.
- `generar_datos.py`: Script de generación del dataset.
- `inventario_datos.csv`: Dataset con 100 productos registrados.
- `requirements.txt`: Librerías requeridas.
- `.gitignore`: Filtro de archivos no rastreados por Git.
- `Informe_Consultoria.pdf`: Documento formal de consultoría.
